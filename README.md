# 乾隆御製詩 · 全文數據庫與檢索查看器

清高宗愛新覺羅·弘曆（乾隆帝，1711–1799）一生作詩逾四萬首，為歷史上存詩最多的帝王。其詩以編年為次，收於《欽定四庫全書》集部《御製詩集》初集、二集、三集、四集、五集（另有《樂善堂全集》及餘集）。

本項目提供兩件成品：

| 成品 | 路徑 | 說明 |
| --- | --- | --- |
| **檢索查看器** | [`dist/qianlong-poems.html`](dist/qianlong-poems.html) | 單一 HTML 檔案，內嵌數據與繁簡折叠表，**雙擊即可離線使用**，無需服務器、無外部依賴 |
| **全文數據庫** | [`data/poems.json`](data/poems.json) | 結構化 JSON，含詩題、詩文、分集、卷次、干支紀年、公元年、出處等字段 |

收錄《御製詩集》初集至五集及餘集**全部 454 卷**，共 **37,728 首**（其中 33,866 首可繫公元年，起 1736 訖 1798）。據各集卷首自記，全書約四萬二千餘首；本庫凡能自底本可靠切分者均已入庫，差額為四庫本中詩題跨行、敬稱抬格等難以自動還原的部分（見下文「已知邊界」）。

> 另附 `dist/qianlong-poems.json`（查看器所用的壓縮字段版數據庫），便於前端二次引用。

## 一、查看器功能

打開 `dist/qianlong-poems.html` 即可使用。

**檢索**
- **詩題、詩句雙維度**檢索，命中處以琥珀色高亮。
- **可選搜索模式**（「範圍」下拉）：
  - `綜合（詩題×3＋詩句）` —— 詩題命中權重更高，相關度排序更貼合直覺；
  - `僅詩題` / `僅詩句` —— 精確限定命中位置；
  - `僅年份／紀年` —— 以公元年或干支（如 `丙辰`）檢索；
  - `正則（詩題＋詩句）` —— 支援 `春.花` 一類正則式高階檢索。
- **可選模糊查找**：`模糊查找` 支援子序列散配（如「春風」可命中「春」與「風」不相鄰的詩句），`精確匹配` 要求連續成詞。
- **繁簡互通**：以簡體輸入「贞观」「画」，同樣可命中原文為繁體的《讀貞觀政要》《畫梅》。
- **年份篩選**：公元年起止輸入，或點擊 `初集`～`五集` 快捷年份段。

**瀏覽**
- **年份分佈直方圖**（點擊「統計」展開）：每根柱為一年，點擊柱條即按該年篩選。
- **排序**：相關度 / 年份升 / 年份降 / 篇幅降 / 詩題。
- **詩文自動版面化**：按字數推断五言、七言，逐句成行並仿古籍作奇偶縮進。
- **隨機一首**、**每日一詩**（以日期為種子，當日固定）。

**效率與留存**
- 收藏（星標，存於瀏覽器 `localStorage`）與「只看收藏」。
- 匯出檢索結果 / 匯出全庫 / 匯入補充資料（JSON）。
- 檢索條件與當前篇目寫入 URL hash，可直接分享連結。
- 深色模式；全部狀態本地保存。
- 鍵盤快捷鍵：<kbd>/</kbd> 聚焦檢索、<kbd>R</kbd> 隨機、<kbd>D</kbd> 每日一詩、<kbd>J</kbd>/<kbd>K</kbd> 下一篇/上一篇。

## 二、數據結構

`data/poems.json`：

```jsonc
{
  "meta": { "subject": "...", "version": "...", "edition": "...", "stats": { /* 篇數、繫年覆蓋、分集分佈 */ } },
  "poems": [
    {
      "id": "ql-00001",
      "title": "讀貞觀政要",
      "content": "懿德嘉言在簡編憂勤想見廿三年……",  // 依源文，未加標點
      "ji": "初集",          // 分集
      "juan": 1,             // 卷次
      "ganzhi": ["丙辰"],    // 干支紀年
      "year": 1736,          // 公元年（據干支與分集推定；0 表示未詳）
      "year_text": "乾隆元年（丙辰）",
      "tags": ["读书", "治国", "七律"],
      "source": "《御製詩初集》卷一",
      "note": "讀《貞觀政要》有感……",
      "provenance": { "source_of_record": "...", "url": "...", "retrieved": "..." }
    }
  ]
}
```

查看器使用壓縮字段（`t/c/y/yt/ji/j/gz/tg/src/nt/prov`）以縮小體積；`tools/build.js` 負責兩種形式的轉換。

## 三、數據可靠性與溯源

### 數據源（Source of Record）

| 層級 | 來源 | 用途 |
| --- | --- | --- |
| 一手底本 | 《欽定四庫全書》集部《御製詩集》（KR4f0005） | 詩文正文、分集、卷次、干支紀年 |
| 公開文本 | Kanseki Repository 漢籍リポジトリ（逐卷公開，可逐字核校） | 抓取與解析對象 |
| 交叉核驗 | 故宮博物院、中國人民大學清史研究所等學術文本所引御製詩 | 代表作的出處覆核 |

《御製詩集》各集卷數（據四庫本提要及故宮博物院研究）：初集 44 卷、二集 94 卷、三集 100 卷、四集 100 卷、五集 100 卷，另有餘集 16 卷，合計 454 卷。本庫各集入庫篇數：初集 3,069、二集 6,935、三集 10,199、四集 9,201、五集 7,549、餘集 775。

### 派生鏈（Derivation Chain）

```
git clone kanripo/KR4f0005（欽定四庫全書本《御製詩集》逐葉轉錄，454 卷）
  └─ tools/fetch-kanripo.js   克隆／增量更新底本倉庫                            .work/repo/KR4f0005_NNN.txt
       └─ tools/import.js     以各集《目録》比對定位詩題：還原跨行、抬格詩題，
                              區分序文／按語與詩句，干支紀年映射公元年
            └─ tools/build.js 合併精選語料、去重、編號、生成繁簡折叠表與內嵌數據
                 └─ dist/qianlong-poems.html / data/poems.json
```

每一步均可重跑復現：`fetch` 僅依賴公開 Git 倉庫，`import`/`build` 為純函數式轉換。

### 溯源與重算

- **每條記錄可回溯**：`source` 給出著錄出處，`provenance.source_of_record` 與 `provenance.url` 指向可核對的原文。
- **重算方法**：若某卷底本修訂，僅需重新抓取該卷、重跑 `node tools/import.js`，再執行 `node tools/build.js` 重建全庫。
- **傳播範圍**：數據庫與查看器均由 `data/poems.json` 單點派生，重算即自動覆蓋，無其他下游副本。

### 已知邊界（誠實聲明）

四庫本詩題常跨行、敬稱抬頭、部分詩作有回指標題（「右題…」），自動切分已針對這些情形做了處理，但**古詩自動分篇仍可能存在少量偏差**（如長篇組詩的邊界）。查看器以「保守切分、不臆造標點、不改寫正文」為原則，原文一字未增刪。若用於嚴謹學術引用，請以 `provenance.url` 指向的底本為準。

## 四、復現與更新

```bash
# 0. 取底本（首次克隆 GitHub 倉庫 kanripo/KR4f0005；再次執行則增量更新）
node tools/fetch-kanripo.js

# 1. 重建數據庫與查看器（合併語料 → 去重編號 → 折叠表 → 內嵌單文件）
node tools/build.js

# 2. 僅解析單卷以檢視切分效果
node tools/import.js .work/repo/KR4f0005_001.txt out.json
```

底本修訂後，重跑上述 0–1 步即可全量覆蓋重建。

`tools/import.js` 亦可直接匯入自行準備的四庫本 / TXT 文本（支援分頁標記 `<pb:...>`、`古今體N首干支/` 紀年行等）。

## 五、目錄結構

```
qianlong-poems/
├── dist/
│   ├── qianlong-poems.html    # ★ 單文件查看器（離線可用）
│   └── qianlong-poems.json    # 查看器用壓縮數據庫
├── data/
│   ├── poems.json             # ★ 完整數據庫
│   └── seed.json              # 人工核校的精选語料（含溯源）
├── app/
│   └── viewer.template.html   # 查看器源模板（構建時注入數據）
├── tools/
│   ├── fetch-kanripo.js       # 分卷抓取與清洗
│   ├── import.js              # 分卷文本 → 結構化詩作
│   └── build.js               # 合併構建數據庫與查看器
└── README.md
```
